# Games, simulations & mathematics

I build small games, physics simulations and mathematical experiments in Python. These projects explore the underlying mechanics: vectors, matrices, motion, forces and projection.

## Games

| Project | What it does |
| --- | --- |
| [Asteroids](https://github.com/lnivan/asteroids) | A vector-style arcade game with a controllable spaceship, missiles and asteroids. |
| [Parabola Targets](https://github.com/lnivan/parabola-targets) | A projectile puzzle: aim parabolic shots around obstacles to hit targets. |

## Simulations

| Project | What it explores |
| --- | --- |
| [Ragdoll Physics](https://github.com/lnivan/ragdoll-physics) | Point masses, spring-damper joints and distance constraints in an interactive ragdoll. |
| [Spring–Mass Simulator](https://github.com/lnivan/spring-mass-simulator) | Damped springs and flexible strings built from a custom 2D physics model. |
| [Wireframe 3D](https://github.com/lnivan/wireframe-3d) | Perspective projection and a movable camera, implemented with custom vectors and matrices. |

## Math

| Project | What it explores |
| --- | --- |
| [Geometry Viewer 3D](https://github.com/lnivan/geometry-viewer-3d) | Vector algebra, matrix rotations and camera coordinates in an interactive geometry viewport. |

Each repository includes setup instructions, controls, a screenshot and notes on its current limitations.

**Built with:** Python · Pygame · NumPy
