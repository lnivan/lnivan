I'm a maths undergrad. This is where I post projects I've made over the years, from games and physics simulations I started writing in high school to small tools and whatever I'm working on now. Most of it is Python, with Pygame for anything visual.

The repositories were only uploaded in 2026, so their commit dates are recent. Each README gives a rough date for when the project was written, explains how to run it, and lists what is still unfinished.
